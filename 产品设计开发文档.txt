## 1. 技术栈与架构

### 1.1 核心技术栈

#### 前端框架
- **React**: ^19.2.6
- **TypeScript**: ~6.0.2
- **Vite**: ^8.0.12
- **React Router**: ^7.16.0

#### 状态管理
- **Zustand**: ^5.0.14

#### 数据库
- **Dexie.js (IndexedDB 封装): ^4.4.3

#### UI组件库
- **Konva / React-Konva (画布渲染): konva: ^10.3.0; react-konva: ^19.2.4
- **TipTap (富文本编辑):
  - @tiptap/react: ^3.23.6
  - @tiptap/starter-kit: ^3.23.6
  - @tiptap/extension-image: ^3.23.6
  - @tiptap/extension-mathematics: ^3.24.0
  - @tiptap/extension-color: ^3.23.6
  - @tiptap/extension-font-family: ^3.23.6
  - @tiptap/extension-highlight: ^3.23.6
  - @tiptap/extension-text-align: ^3.23.6
  - @tiptap/extension-text-style: ^3.23.6
  - @tiptap/extension-underline: ^3.23.6

#### 工具库
- **KaTeX (LaTeX 公式渲染): ^0.17.0
- **html2canvas (HTML转图片): ^1.4.1
- **jspdf (PDF 生成): ^4.2.1
- **uuid (ID生成): ^14.0.0
- **lucide-react (图标库): ^1.17.0
- **@dnd-kit (拖拽排序): ^6.3.1, ^10.0.0, ^3.2.2

### 1.2 架构概览

KnowCard 使用前端单页应用(SPA)架构：
- 使用 Zustand 进行全局状态管理
- 数据持久化使用 IndexedDB（通过 Dexie.js
- 画布渲染使用 Konva
- 富文本编辑使用 TipTap
- 公式渲染使用 KaTeX
- 图片导出使用 html2canvas

## 3. 数据库设计

### 3.1 数据库版本历史

使用 IndexedDB 数据库名称：`KnowCardDB`

版本：
- v1: 核心数据表
- v2: 添加样式和内容预设
- v3: 添加尺寸预设
- v4: 添加用户系统

### 3.2 数据表结构

#### 1. **projects** (项目表)
```javascript
{
  id: string,           // 项目ID（UUID）
  name: string,
  description: string,
  createdAt: number,  // Unix 时间戳
  updatedAt: number
}
索引：id, createdAt

#### 2. **pages** (页面表)
```javascript
{
  id: string,
  projectId: string,
  name: string,
  size: 'A4' | 'A3',
  orientation: 'portrait' | 'landscape',
  margins: {
    top: number,
    bottom: number,
    left: number,
    right: number
  },
  pageNumber: {
    enabled: boolean,
    position: 'top-left' | 'top-center' | 'top-right' | 'bottom-left' | 'bottom-center' | 'bottom-right',
    font: string,
    color: string,
    size: number
  },
  footer: {
    enabled: boolean,
    text: string,
    font: string,
    color: string,
    size: number,
    position: 'left' | 'center' | 'right'
  },
  watermark: {
    enabled: boolean,
    text: string,
    fontSize: number,
    opacity: number,
    density: number,
    spacing: number,
    color: string
  },
  cardMinHSpacing: number,
  cardMinVSpacing: number,
  order: number,
  backgroundColor: string,
  createdAt: number,
  updatedAt: number
}
索引：id, projectId, order

#### 3. **cards** (卡片表)
```javascript
{
  id: string,
  projectId: string,
  pageId: string,
  title: string,
  name?: string,
  content: object,
  style: {
    titleFont: string,
    titleFontSize: number,
    titleBold: boolean,
    titleColor: string,
    titleBackgroundColor: string,
    bodyFont: string,
    bodyFontSize: number,
    bodyColor: string,
    bodyBackgroundColor: string,
    borderColor: string,
    borderWidth: number,
    borderRadius: number
  },
  size: {
    defaultWidth: number,
    defaultHeight: number,
    projectWidth: number,
    projectHeight: number
  },
  flags: {
    hideBorder: boolean,
    hideTitle: boolean,
    hideBody: boolean,
    showNumber: boolean,
    excludeFromLayout: boolean,
    excludeFromNumbering: boolean
  },
  position: {
    x: number,
    y: number
  },
  groupId?: string,
  order: number,
  createdAt: number,
  updatedAt: number
}
索引：id, projectId, pageId, groupId, order

#### 4. **cardGroups** (卡片分组表)
```javascript
{
  id: string,
  projectId: string,
  name: string,
  color: string,
  order: number
}
索引：id, projectId, order

#### 5. **pageElements** (页面元素表)
```javascript
{
  id: string,
  pageId: string,
  type: 'text' | 'image' | 'line' | 'arrow' | 'red-box',
  position: { x: number, y: number },
  size: { width: number, height: number },
  rotation: number,
  style: object,
  content: object,
  zIndex: number,
  createdAt: number,
  updatedAt: number
}
索引：id, pageId, zIndex

#### 6. **settings** (设置表)
```javascript
{
  key: string,
  value: unknown
}
索引：key

#### 7. **stylePresets** (样式预设表)
```javascript
{
  id: string,
  name: string,
  style: string,    // JSON 字符串，存储 CardStyle
  createdAt: number,
  pinned?: boolean
}
索引：id, createdAt

#### 8. **contentPresets** (内容预设表)
```javascript
{
  id: string,
  name: string,
  title: string,
  content: string,
  createdAt: number,
  updatedAt: number,
  pinned?: boolean
}
索引：id, createdAt

#### 9. **cardSizePresets** (尺寸预设表)
```javascript
{
  id: string,
  name: string,
  width: number,
  height: number,
  createdAt: number,
  pinned?: boolean
}
索引：id, createdAt

#### 10. **users** (用户表)
```javascript
{
  id: string,
  username: string,
  passwordHash: string,
  isAdmin: boolean,
  createdAt: number,
  updatedAt: number
}
索引：id, username, isAdmin

## 7. 关键算法与工具函数

### 7.1 单位转换

毫米与像素转换
```javascript
const PX_PER_MM = 3.779527559
// 像素转毫米：px / PX_PER_MM
// 毫米转像素：mm * PX_PER_MM
```

### 7.2 页面尺寸计算

A4 尺寸（210 × 297 mm

横向时交换宽高

### 7.3 卡片尺寸计算

计算卡片高度计算：
```javascript
calcCardHeight(content, fontSize, titleFontSize, maxWidth, autoHeight, fixedHeight)

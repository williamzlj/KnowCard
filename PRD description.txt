网页端知识卡片智能排版工具 —— 软件开发需求规格说明书（整理版）

一、项目概述

开发一个网页端的知识卡片智能排版工具，支持知识卡片编辑、智能排版、页面设计、打印导出、项目管理与离线存储。

该工具主要用于：
   •   教学讲义制作
   •   知识卡片整理
   •   A4/A3 页面排版
   •   打印输出
   •   学习资料设计

系统需支持：
   •   富文本知识卡片
   •   卡片拖动与自动防重叠
   •   智能紧凑排版
   •   页面元素编辑
   •   多项目管理
   •   IndexedDB 本地离线存储
   •   PNG 导出与打印


二、技术架构要求

2.1 前端技术栈

推荐：
   •   React + TypeScript
   •   Vite
   •   Zustand（状态管理）
   •   IndexedDB（Dexie.js）
   •   Konva.js 或 Fabric.js（画布与图形编辑）
   •   TipTap 或 Lexical（富文本编辑器）
   •   html2canvas + jsPDF（打印与导出）

2.2 数据存储

所有数据保存在 IndexedDB 中。

支持：
   •   离线使用
   •   自动保存
   •   完整数据库导入导出
   •   项目级数据隔离

卡片基础结构

每个知识卡片包含：

interface Card {
  id: string

  content: RichTextJSON

  style: {
    titleFont
    titleColor
    titleBackgroundColor

    bodyFont
    bodyColor
    bodyBackgroundColor

    borderColor
    borderWidth
  }

    defaultWidth
    defaultHeight
    projectWidth
    projectHeight
  }

  flags: {
    hideBorder
    hideTitle
    excludeFromLayout
    excludeFromNumbering
  }
}



3.3 富文本编辑器

编辑方式

用户双击卡片正文后：
   •   弹出独立编辑窗口
   •   不允许直接嵌入式编辑

编辑器功能

支持：
   •   加粗
   •   斜体
   •   下划线
   •   字体颜色
   •   背景颜色
   •   字号
   •   字体
   •   段落
   •   对齐
   •   换行
   •   图片插入
   •   粘贴图片
   •   图片缩放
   •   图片移动

字体支持

仅允许以下字体：
   •   宋体
   •   黑体
   •   楷体
   •   Arial
   •   Times New Roman
   •   Georgia

富文本渲染要求

卡片正文显示效果必须与编辑器完全一致。

不得出现：
   •   编辑器有样式
   •   卡片显示为纯文本


3.4 卡片列表系统（左侧面板）

功能

支持：
   •   卡片排序拖动
   •   卡片搜索
   •   卡片分组
   •   卡片编号显示
   •   多选
   •   全选
   •   删除
   •   移除
   •   导入已有卡片

删除规则

移除

仅从当前页面隐藏。

彻底删除

从数据库永久删除。

卡片编号

支持：
   •   显示/隐藏
   •   修改编号颜色
   •   常用颜色快捷选择

特殊卡片不参与编号。

卡片管理器

提供独立卡片管理器。

功能包括：
   •   搜索
   •   编辑
   •   删除
   •   多选删除
   •   全选
   •   导入到当前页面

点击编辑后：
   •   打开与“双击卡片正文”相同的编辑界面

不显示卡片宽高信息。

3.5 卡片拖动与交互

基础拖动

支持：
   •   单卡片拖动
   •   多选拖动
   •   框选
   •   吸附

防重叠

卡片不可重叠。

拖动结束后：
   •   自动检测碰撞
   •   自动移动到最近可放置位置

卡片贴合

拖动结束后：
   •   自动贴近最近卡片
   •   保持最小间距

最小间距用户可设置。

3.6 自动排版系统（核心功能）

排版目标

实现：
   •   高密度紧凑排版
   •   最大化利用页面空间
   •   类似瀑布流/紧凑布局

排版规则

第一阶段

卡片从左到右水平排列。

换行规则

当前行放不下时：
   •   自动进入下一行

第二行及后续行

新卡片位置计算时：
   •   不按上一整行最大高度计算
   •   只参考上方最近卡片
   •   同时参考左侧最近卡片

实现真正紧凑布局。

自动排版约束

需要考虑：
   •   页面边距
   •   卡片最小间距
   •   特殊卡片排除
   •   页面安全区域

自动排版按钮

点击后：
   •   按左侧列表顺序自动排版

3.7 卡片尺寸系统

手动尺寸

用户可直接输入：
   •   宽度
   •   高度

自动高度

根据内容自动计算高度。

自动宽度

计算时需综合：
   •   标题宽度
   •   标题编号宽度
   •   正文宽度
   •   中英文差异

避免：
   •   中文标题被截断
   •   英文标题过宽

复制尺寸

支持：
   •   复制上一卡片高度
   •   复制上一卡片宽度

3.8 卡片样式系统

可配置项

支持设置：
   •   标题字体
   •   标题颜色
   •   标题背景色
   •   正文字体
   •   正文颜色
   •   正文背景色
   •   边框颜色
   •   边框粗细

特殊显示

允许：
   •   不显示标题
   •   不显示边框
   •   仅显示正文

样式复制

支持：
   •   复制卡片
   •   复制卡片样式
   •   粘贴卡片样式
   •   应用样式到当前页面所有卡片

应用样式功能必须：
   •   更新当前页面所有卡片
   •   不能只更新最后一个卡片

批量设置

允许将某卡片样式批量应用到其他卡片。

3.9 颜色选择器

功能

颜色设置组件需支持：

箭头系统

   •   可拖动起点终点

文本框

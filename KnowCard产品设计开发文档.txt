## 1. 技术栈与架构

### 1.1 核心技术栈

#### 前端框架
- **React**: ^19.2.6
- **TypeScript**: ~6.0.2
- **Vite**: ^8.0.12
- **React Router**: ^7.16.0

#### 状态管理
- **Zustand**: ^5.0.14

#### 数据库
- **Dexie.js (IndexedDB 封装)**: ^4.4.3

#### UI组件库
- **Konva / React-Konva (画布渲染)**: konva: ^10.3.0; react-konva: ^19.2.4
- **TipTap (富文本编辑)**:
  - @tiptap/react: ^3.23.6
  - @tiptap/starter-kit: ^3.23.6
  - @tiptap/extension-image: ^3.23.6
  - @tiptap/extension-mathematics: ^3.24.0
  - @tiptap/extension-color: ^3.23.6
  - @tiptap/extension-font-family: ^3.23.6
  - @tiptap/extension-highlight: ^3.23.6
  - @tiptap/extension-text-align: ^3.23.6
  - @tiptap/extension-text-style: ^3.23.6
  - @tiptap/extension-underline: ^3.23.6

#### 工具库
- **KaTeX (LaTeX 公式渲染)**: ^0.17.0
- **html2canvas (HTML转图片)**: ^1.4.1
- **jspdf (PDF 生成)**: ^4.2.1
- **uuid (ID生成)**: ^14.0.0
- **lucide-react (图标库)**: ^1.17.0
- **@dnd-kit (拖拽排序)**: ^6.3.1, ^10.0.0, ^3.2.2

### 1.2 架构概览

KnowCard 使用前端单页应用(SPA)架构：
- 使用 Zustand 进行全局状态管理
- 数据持久化使用 IndexedDB（通过 Dexie.js）
- 画布渲染使用 Konva
- 富文本编辑使用 TipTap
- 公式渲染使用 KaTeX
- 图片导出使用 html2canvas

## 3. 数据库设计

### 3.1 数据库版本历史

使用 IndexedDB 数据库名称：`KnowCardDB`

版本：
- **v1**: 核心数据表
- **v2**: 添加样式和内容预设
- **v3**: 添加尺寸预设
- **v4**: 添加用户系统
- **v5**: 添加图片库表
- **v6**: 添加正则表达式库表
- **v7**: 数据库结构优化（图片库添加 createdAt 索引）

### 3.2 数据表结构

#### 1. **projects** (项目表)
```javascript
{
  id: string,           // 项目ID（UUID）
  name: string,
  description: string,
  createdAt: number,    // Unix 时间戳
  updatedAt: number,
  order: number,        // 排序顺序
  isPinned: boolean     // 是否置顶
}
```
索引：id, createdAt

#### 2. **pages** (页面表)
```javascript
{
  id: string,
  projectId: string,
  name: string,
  size: 'A4' | 'A3',
  orientation: 'portrait' | 'landscape',
  margins: {
    top: number,
    bottom: number,
    left: number,
    right: number
  },
  pageNumber: {
    enabled: boolean,
    position: 'top-left' | 'top-center' | 'top-right' | 'bottom-left' | 'bottom-center' | 'bottom-right',
    font: string,
    color: string,
    size: number
  },
  footer: {
    enabled: boolean,
    text: string,
    font: string,
    color: string,
    size: number,
    position: 'left' | 'center' | 'right'
  },
  watermark: {
    enabled: boolean,
    text: string,
    fontSize: number,
    opacity: number,
    density: number,
    spacing: number,
    color: string
  },
  cardMinHSpacing: number,   // 卡片最小水平间距
  cardMinVSpacing: number,   // 卡片最小垂直间距
  order: number,
  backgroundColor: string,
  createdAt: number,
  updatedAt: number
}
```
索引：id, projectId, order

#### 3. **cards** (卡片表)
```javascript
{
  id: string,
  projectId: string,
  pageId: string,
  title: string,              // 标题文本

    titleNumberStyle?: 'number' | 'number-dot' | 'number-hash' | 'number-hash-prefix' | 'number-dash' | 'number-space',

    bodyFont: string,

    x: number,
```

## 5. 核心功能模块

### 5.1 用户认证模块

#### 功能
1. 用户注册
2. 用户登录
3. 修改用户名
4. 修改密码
5. 用户管理后台（仅管理员可见）

#### 登录页面布局
- 渐变背景：#667eea → #764ba2
- 输入框：圆角，支持切换登录/注册
- Logo 和产品名称
- 作者介绍
- 数据存储说明

#### 用户管理后台功能
- 查看所有用户列表
- 修改用户权限（普通用户/管理员）
- 重置用户密码
- 删除用户
- 不能删除自己

#### 密码安全
- 密码使用 SHA-256 哈希存储
- 使用固定盐值增强安全性

### 5.2 项目管理模块

#### 功能
1. **项目创建**：输入项目名称创建新项目
2. **项目导入**：导入 JSON 格式的项目文件
3. **项目列表展示**：网格布局显示所有项目
4. **项目导出**：导出单个项目的 JSON 数据
5. **项目删除**：删除项目（需确认）
6. **项目重命名**：双击项目名称进入编辑模式
7. **项目复制**：复制项目
8. **项目置顶**：置顶显示项目
9. **项目重排序**：拖拽调整项目顺序
10. **项目多选**：复选框选择多个项目
11. **批量导出项目**：将选中项目合并到一个 JSON 文件
12. **批量删除项目**：一次性删除多个选中的项目
13. **用户设置导出**：导出资料库、图片库、尺寸库、样式库、正则表达式资料库
14. **数据库管理**：完整数据库导出/导入/重置

#### 项目管理页面布局
- 项目网格布局：一行显示 4 个项目卡片
- 第一行：新建项目输入框 + 创建按钮 + 导入按钮
- 第二行：导出用户设置、导出数据库、导入数据库、重置数据库、正则替换、资料库、图片库按钮
- **批量操作区**：仅在有选中项目时显示
  - 全选/取消全选按钮
  - 批量导出按钮（显示选中数量）
  - 批量删除按钮（红色警告样式，显示选中数量）
- 项目卡片：
  - 复选框（支持多选）
  - 置顶按钮（红色图标表示已置顶）
  - 项目名称（可双击编辑）
  - 项目描述
  - 更新时间
  - 操作按钮：导出、删除

#### 批量操作功能
- **项目多选**：点击项目卡片上的复选框选择项目
- **全选/取消全选**：一键选中或取消所有项目
- **批量导出**：
  - 将所有选中项目的数据合并到一个 JSON 文件
  - 文件名格式：`KnowCard_项目1名称_项目2名称_YYYYMMDD.json`
  - 如果项目名称拼接超过 25 字符，自动截断为前 25 字符并添加 `…等X个文件`
  - JSON 结构包含 `type: 'multi-project'` 标记
- **批量删除**：
  - 删除前显示确认对话框
  - 一次性删除所有选中的项目
  - 操作后清空选中状态

## 7. 关键算法与工具函数

### 7.1 单位系统

#### mm 与 px 转换
```typescript
const PX_PER_MM = 3.779527559  // 1 mm = 3.779527559 px（96 DPI）
const MM_TO_PX = 3.779527559

// 转换公式
mm = px / PX_PER_MM
px = mm * MM_TO_PX
```

### 7.2 自动排版算法

#### 水平排版 (applyCompactLayout)
- 逐卡放置，像素级扫描
- 复杂度：O(N × W)

#### 竖直排版 (applyCompactLayoutVertical)
- 按列排列，Y 方向排满后 X 方向扩展
- 复杂度：O(N × C)，C 为列数

### 7.3 卡片尺寸计算

#### 字符宽度估算
```typescript
// 中文字符：宽 = fontSize
// 英文字符：宽 = fontSize * 0.6
```

#### 卡片高度计算
```typescript
// 逐行文本模拟自动换行
// 公式行高度 = fontSize * 1.8 + 2 px
```

### 7.4 富文本解析

#### TipTap JSON → 渲染行
- 支持段落、标题、图片、公式、列表
- 公式正则：`/\$\$([^\n$]+?)\$\$|\$([^\n$]+?)\$/g`

## 12. 重构指南

### 12.1 跨平台重构注意事项

1. **单位转换**：保持 PX_PER_MM = 3.779527559 常量不变
2. **IndexedDB**：可替换为其他本地存储方案（SQLite、LocalStorage）
3. **Konva**：可替换为 Fabric.js 或原生 Canvas
4. **TipTap**：可替换为其他富文本编辑器（Quill、Slate）

### 12.2 性能优化建议

1. **卡片渲染**：使用虚拟列表优化大量卡片渲染
2. **公式渲染**：缓存已渲染的公式图片
3. **自动排版**：使用 Web Worker 避免阻塞主线程

### 12.3 安全性建议

1. **密码存储**：使用 bcrypt 或 Argon2 替代 SHA-256
2. **XSS 防护**：富文本内容需要严格过滤
3. **导入验证**：导入 JSON 时验证数据结构
